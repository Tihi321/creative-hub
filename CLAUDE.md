# Creative hub

This folder connects the user's creative tools (Scriptorium, Book Translator, VN Studio, Cartoon Studio, Pixel Studio, Chiptune Studio, VibeTTS, ComfyUI, LM Studio, Strata). `README.md` is the map; `services.json` is the registry.

- For any request to make a book, translation, art, music, voices or a visual novel from an idea, use the `make-visual-novel` skill.
- For a short film, cartoon or video from an idea or a book, use the `make-video` skill.
- For any request to make an educational game, a quiz, a course, a language-learning game or an Encarta/MindMaze-style game from a topic, use the `make-edu-game` skill (Edu Studio, port 7463). Voice allocation applies to its voices too (Gemini TTS within the free quota, VibeTTS for the rest).
- For a cartoon episode or a cartoon series (cutout puppets, 5-10 min, hr/en), use the `make-cartoon` skill (Cartoon Studio, port 7465). Voice allocation applies.
- Video spends Flow credits: agree a budget first (default 150 per production); `scripts/video-plan.mjs` keeps the estimate and each call's `max_credits`.
- Check and start services with `scripts\hub.ps1` (status, start, stop, build, logs). Never start Scriptorium without asking: it resumes its whole book factory and may spend on paid models.
- Keep one log per production in `runs/<slug>.md` with every id and decision, so another session can resume.
- `ROADMAP.md` holds the hub's tasks: live checks, productions and features that span two or more tools, each a `HUB-NN` ticket with a plan in `.claude/tickets/HUB-NN-<name>/plan.md`, done one by one. A gap that touches only one tool goes in that tool's own `ROADMAP.md`, in its repo. Change a tool's code only in its own repo, on a branch named after a ticket in that repo's style (e.g. `VNO-04_story-tools`).
- Adding a tool: `services.json`, `.mcp.json`, the README table, the skill, the roadmap.
- Voice allocation (ElevenLabs free tier, Google Voice Gemini TTS, local voices): languages are allocated whole, Croatian first, then English. (1) ElevenLabs free tier, about 10,000 credits a month: read the remaining credits from the API before every run; a language whose lines fit in what is left goes to ElevenLabs. Never a paid plan, never past the free quota, never a paid-only endpoint or format. The user alone creates the account and the API key and puts the key in the `ELEVENLABS_API_KEY` or `ELEVEN_CREATOR_KEY` environment variable or `~/.flow-music-mcp/.env`; it never appears in a repo, a log, a run log or a commit. It is called through flow-music-mcp (`flow_narrate` engine `elevenlabs`); today only Cartoon Studio uses it. Keep each character's ElevenLabs voice id in the series bible and reuse it in every episode. (2) Gemini TTS free tier, 10 requests a day: a language that does not fit in ElevenLabs goes to Gemini if its lines fit in today's remaining requests. (3) Otherwise the language goes to the local voices (VibeTTS; in Cartoon Studio Croatian is OmniVoice through ComfyUI first, Supertonic through VibeTTS as the fallback). If both languages are needed and together exceed a free quota, Croatian takes the free cloud voice and English moves to the next step down.
- Record what was verified and what was not. A production is done only when the user has played it.
